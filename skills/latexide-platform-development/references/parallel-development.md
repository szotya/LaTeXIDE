## P18 standalone compiler execution and inherited descriptors

Read `docs/development/results/P18.md` and `integration/requests/P18.json`. The module is compiled by `crates/latexide-core/tests/security_policy_contract.rs` through the independent module seam; it is not a production Runtime/VFS/P09/BuildSupervisor or native Stop/Join integration. Preserve the current deny-default sandbox, host-owned generation lease, explicit environment and ordinary process-group ownership.

On macOS, `execution/child_exec` prepares all CString storage, opaque spawn attributes and file actions in the parent. The final child-only pre-exec operation uses Darwin `POSIX_SPAWN_SETEXEC | POSIX_SPAWN_CLOEXEC_DEFAULT` and explicit inherit actions for only 0/1/2. Successful SETEXEC replaces the same child PID/group. Every returned error goes through Rust's existing exec-error channel; there is no unrestricted retry/fallthrough or parent FD enumeration/relabel/close. This relies on the Darwin spawn implementation, not a portable POSIX guarantee about calling arbitrary functions after fork. Extra inherited compiler pipes are not authorized; compiler-created pipes after exec are a separate tested case. Review the exact target SDK/implementation when changing this unsafe boundary.

Mac snapshot capture must rename the still-private0700 staging directory exclusively inside its private0700 generation before descriptor-based sealing to0500: Mac15 rejects renaming the already write-disabled root (EACCES), while later local systems may permit it. Retain the host-authority lease across rename, sealing, sealed-mode/uid/byte/identity validation and cancellation. All files are0400 before rename; no Ready token, compiler launch or output preparation may occur in the intermediate window. The renamed filesystem path is not a published host capability. Keep the three exact real rename-window regressions for lease/modes, same-size+mtime snapshot tamper and cancellation, plus no-overwrite and final validate_files checks. Do not treat this as same-UID immutability or OS-atomic publication; qualify the actual target OS rather than extrapolating a local pass.
