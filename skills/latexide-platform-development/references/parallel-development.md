Other packages use separate branches and exclusive `owned_paths`; existing shared runtime, editor/store, registry, Cargo/lockfile, handoff and ledger changes are integrated by P00 from `integration/requests/<ID>.json`. P00 now implements the start gate on `feature/p00-integration`: read `docs/development/contracts/v1.md` and `docs/development/results/P00.md` for the exact status/source. Workers compile owned Rust modules by path import against the shared dependency; P00 registers production modules at integration. The tested standalone example is `tests/contracts/seam`. Do not add empty Cargo features pointing at nonexistent modules.

Canonical snapshot UTF-8 excludes disk BOM and normalizes CRLF as the existing core does; the runtime retains serialization metadata. Never save directly from a decoded snapshot. Digest validation here checks format/binding, not producer authenticity or filesystem identity. Contract envelope1.0 and legacy authenticated IPCv1 are separate; port models grant no MCP capabilities. `CallContext` comes from the trusted caller, not the client.

Run `python3 integration/registry/generate_contracts.py --check` and `python3 integration/registry/verify.py --profile contracts`. The `shared` profile adds the whole Rust workspace; `--native-schema` is a Mac Codable decode test, not native UI qualification. Reports/logs remain under ignored `.local`; preserve unrun and source/artifact identity. A failed build must not run an earlier binary as current evidence. Full QA-08/14/OS-10 and real provider/platform qualification remain separate work.

Preserve the single authoritative Rust state, expected revisions, UTF-16 coordinates, direct agent edits, explicit save and undo after save. A port/DTO is not automatically a newly allowed MCP tool. Shared types must avoid the existing protocol→core dependency becoming a cycle; the planned contracts crate is independent of both.

Before implementing a package, reconcile the current handoff with the dated audit. In particular, own macro/ref/cite Cmd-click is already implemented; P06 adds remaining scope/peek/history behavior. Do not reclassify the earlier audit's tests as current source verification.
