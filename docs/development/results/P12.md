# P12 — read-only bibliography library and literal comment recovery

## Scope — 2026-11-14

Partial **LANG-11** backend/library slice, related to [issue #13](https://github.com/szotya/LaTeXIDE/issues/13). No full requirement or issue acceptance is claimed.

`latexide_core::services::bibliography` exposes `LocalBibliographyProvider`, `inspect_bibliography` and `parse_bibliography` through the existing contract-v1 DTO/port. A malformed header such as `@article broken` is bounded to its line, so a following valid entry is inspected instead of swallowed. Original source bytes and the contiguous fragment partition remain intact.

Delimited `@comment` payloads balance their matching delimiters and retain quotes and percent signs literally. An unmatched quote or a percent sign inside a closed comment therefore does not swallow the next entry. Entry values, `@string` and `@preamble` retain their existing scanner semantics. Public parser documentation distinguishes borrowed UTF-8 fragment offsets from UTF-16 report ranges.

The controlled oracle covers exact duplicate keys, nested braces, escaped quotes, comments/directives, literal macro concatenation, incomplete entries/fields, astral Unicode/UTF16 ranges, logical FEFF, CRLF and empty input. Four additional recovery cases cover malformed headers, valid next-line openers, nested quoted literals and comment boundaries. Values remain raw lexemes; this is not macro/crossref/xdata or BibLaTeX schema resolution.
