## GitHub permissions

Public visibility does not grant write, merge or administration access to
this repository. Only the owner and explicitly authorized accounts have those
permissions, subject to repository rules. Existing collaborators and pending
invitations are managed separately from visibility and licensing.

Visitors can report issues and propose changes through pull requests where
the repository's interaction settings permit. A fork or pull request does
not grant access to push to the upstream repository or merge changes there.
GitHub's Terms of Service separately govern on-platform viewing and forking.

An accepted contribution may make its author appear in GitHub's contributor
list. That attribution does not grant collaborator permissions.
